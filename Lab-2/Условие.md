# Лабораторная работа №2

Представьте себе издательскую компанию, которая торгует книгами и
аудиозаписями этих книг. Создайте класс Publication, к котором хранятся название
(строка) и цена (float) книги. От этого класса наследуются еще два класса: book (с
информацией о количестве страниц в книге) и type (со временем записи книги в минутах).
В каждом из этих классов должен быть метод getdata(), через который можно получать
данные от пользователя с клавиатуры, и putdata(), предназначенный для вывода этих
данных.
