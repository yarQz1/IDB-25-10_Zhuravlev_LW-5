# Лабораторные работы

Данный репозиторий содержит все четыре лабораторные работы, включая дополнительные задания к ним.

## Структура репозитория

Каждая лабораторная работа хранится в отдельной директории и имеет следующую структуру:

- **`Lab-X/`** — основная часть лабораторной работы №X (обязательные задания);
- **`Lab-X-Additional/`** — дополнительные задания к лабораторной работе №X, вынесенные в отдельную папку.

## Список лабораторных работ

| № | Директория | Дополнительные задания |
|---|------------|------------------------|
| 1 | `Lab-1` | `Lab-1-Additional(B/W)` |
| 2 | `Lab-2` | `Lab-2-Additional` |
| 3 | `Lab-3` | `Lab-3-Additional` |
| 4 | `Lab-4` | `Lab-4-Additional` |

## Примечание

Дополнительные задания к каждой лабораторной работе находятся в соответствующей папке с суффиксом `-Additional` и не входят в основную директорию лабораторной.
