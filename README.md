# Лабораторная работа №5

Данный репозиторий содержит четыре лабораторные работы, включая дополнительные задания к ним.

## Структура репозитория

Каждая лабораторная работа хранится в отдельной директории и имеет следующую структуру:

- **`Lab-X/`** — основная часть лабораторной работы №X 
- **`Lab-X-Additional/`** — дополнительные задания к лабораторной работе №X, вынесенные в отдельную папку, у первой Лабораторной два доп задания, поэтому у них на конце в скобках указан пункт (B) и (W) соответсвенно.
